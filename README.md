# PongGame

A simple Pong game for iOS built with Swift and SpriteKit.

## Features

- Classic Pong gameplay in portrait orientation
- Player vs AI opponent
- Touch controls — drag to move your paddle
- Score tracking with first-to-7 wins
- Dashed center line and retro aesthetic

## Requirements

- Xcode 15+
- iOS 16.0+
- Swift 5

## How to Run

1. Open `PongGame/PongGame.xcodeproj` in Xcode
2. Select an iPhone simulator or device
3. Press **Cmd+R** to build and run

## How to Play

- **Tap** the screen to serve the ball
- **Drag** your finger to move the bottom paddle left/right
- Score 7 points before the AI to win
